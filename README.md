# Kiro AI Grading System
Multi-tenant AI-powered educational grading and academic integrity platform built for the Kiro University Challenge.

## Overview

A multi-tenant educational assessment platform that provides:

- Institution management
- Role-based access control
- Course management
- Assignment management
- AI grading
- Plagiarism detection
- Student analytics
- Academic integrity reporting

## User Roles

### System Manager
- Manage institution
- Manage staff
- Manage teachers
- Manage students
- Manage courses

### Staff
- Manage users
- Support course administration

### Teachers
- Manage own courses
- Create assignments
- Review AI grading
- Override grades

### Students
- Submit assignments
- View grades
- View feedback
